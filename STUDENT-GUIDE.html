RC2 학생 테스트 안내

이름·계정 없이 플레이하세요. 테스트판은 정식 공개판과 따로 저장됩니다.

  1. 테스트 카페로 가기 → 내 카페 키우기.
  2. 새로 시작하거나 ‘기존 공개 카페 가져오기’를 누르세요. 공개판에 백업 버튼이 없으므로 같은 기기·같은 브라우저에서 복사합니다. 기존 카페를 키웠던 공개판에 먼저 접속해 주세요. 원본은 변경되지 않습니다.
  3. 다른 기기라면 기존 기기에서 테스트판으로 가져온 뒤 ‘카페 JSON 백업’을 다운로드하고, 새 기기의 테스트판 ‘백업 복원’으로 가져오세요. 브라우저 저장은 다른 기기에 자동 이전되지 않습니다.
  4. 오늘 공부할 수학·국어 문제팩을 고르고 15분 영업하세요. 정답이면 음식이 만들어집니다.
  5. 문제풀이 시간은 계속 흐릅니다. 미니게임 실제 조작 중에는 제한된 시간만 정지하며, 새로고침으로 영업시간이 늘어나지 않습니다.
  6. 결과표·복습지를 받고 카페 JSON도 백업하세요. 다시 접속해 카페가 유지되는지 확인하세요.

마을 탐험·가구 배치·직원 채용은 영업 전후에 해보세요. 이 무료 정적 테스트 주소에서는 실시간 교실 호스트를 제공하지 않습니다.

브라우저 저장 삭제·기기 교체 전에 JSON 백업이 필요합니다. 테스트판 초기화는 기존 공개판 저장을 지우지 않습니다. 개인정보가 포함된 파일을 제출하지 마세요.
